# Prieto IA — descargas

Dictado por voz para Windows. Mantienes una tecla, hablas, y el texto aparece donde
tengas el cursor.

**Descarga:** https://prietoia.com/descargar

---

Este repositorio existe **solo para alojar el instalador**. No tiene código adentro.
El programa es privado; acá solo viven las descargas para que el enlace de la web
siempre funcione.

⚠️ Windows dirá «editor desconocido» la primera vez: es normal en programas nuevos que
todavía no tienen certificado de firma. Dale a **Más información → Ejecutar de todas
formas**.

Soporte: privacidad@prietoia.com · https://prietoia.com
